## Build System

This theme now uses the nm-stylus-library design system. To work with styles:

1. Install dependencies: `npm install`
2. Build CSS: `npm run build`
3. For development: `npm run watch`

The Stylus source files are in `src/styl/` and the compiled CSS is output to `dist/style.css`.
